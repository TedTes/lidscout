LidScout architecture and agent moving parts

This diagram separates product roles from deployment roles: Next.js frontend, FastAPI API, Supabase/Postgres state, Redis broker, Celery beat scheduler, Celery workers, external sources, LLM services, and delivery channels.

Architecture lens Frontend reads state and records feedback. API owns auth, repositories, and commands. Workers perform continuous research jobs.

Runtime components and roles

Web client

Next.js app router UI for market dashboards, gaps, themes, findings, sources, reports, activity, and onboarding.

Next.js React TypeScript Tailwind

User actions

Users create market scope, add companies/sources, save or dismiss gaps, edit the brief, and ask follow-ups.

  • Market setup
  • Source management
  • Feedback and preferences

Delivery surfaces

Outputs land in the app first, then email and alerts for passive consumption.

  • Gaps dashboard
  • Weekly digest
  • Threshold alerts

FastAPI service

HTTP boundary for auth, market-scoped reads, feedback writes, pipeline commands, and source management.

FastAPI Pydantic Repository ports

Application services

Business use cases sit behind the API and workers: source suggestions, ingestion, filtering, scoring, clustering, synthesis, reporting.

  • SourceSuggestionService
  • IngestionService
  • OpportunitySynthesisService

Feedback controller

Stores user preference signals that influence ranking, source suggestions, and future research runs.

  • Agent feedback
  • Agent preferences
  • Agent follow-ups
Research agent loop background
1

Celery beat schedules runs

Periodic schedule enqueues market scans into Redis.

2

Celery worker executes pipeline

Worker loads market scope, active sources, preferences, and adapters.

3

Fetch and normalize sources

External source responses become RawPost records with market/company/source metadata.

4

Filter relevance

Rules and LLM classification remove wrong-subject, no-pain, promotional, and off-scope posts.

5

Extract findings

LLM extracts structured pain signals with evidence text, URL, severity, urgency, and category.

6

Score and cluster

Embeddings and scoring group findings into recurring themes.

7

Qualify strategic gaps

Reject thin evidence, single-tool themes, vendor fixes, and off-niche clusters before Gaps.

8

Synthesize and report

Qualified themes become opportunities. Reports, activity events, and alerts are written.

Supabase / Postgres

Primary durable state for source configuration, evidence, analysis outputs, agent memory, and telemetry.

  • user_niches, niche_companies, niche_sources
  • raw_posts, signals, scores, clusters, opportunities
  • agent_activity, preferences, alerts, metrics

Redis

Celery broker for scheduled/background jobs. Keeps API request-response path separate from long research runs.

Broker Queue Task dispatch

External services

Source APIs and AI providers used by the worker pipeline.

  • HN, GitHub, Stack Exchange, Discourse, RSS, websites
  • OpenAI LLM and embeddings
  • Resend email delivery

End-to-end request and worker paths

1. Browser User opens market dashboard or records feedback.
2. API route FastAPI validates auth and market ownership.
3. Service/repository Application service reads or writes domain state.
4. Postgres Persistent rows are loaded or updated.
5. Serialize API returns market-scoped DTOs.
6. Render Next.js components display gaps, themes, sources, and activity.
7. Feedback User actions update future ranking and research behavior.
1. Beat Schedule triggers run cadence.
2. Redis Task is queued for a worker.
3. Worker Loads market scope and active sources.
4. Sources Fetches public data from APIs and pages.
5. AI services Classifies relevance, extracts findings, embeds, synthesizes.
6. Gates Relevance and strategic-gap qualification prevent noise.
7. Persist Writes evidence, analysis, activity, metrics, and reports.

Quality gates

These are the main defenses against bad outputs reaching the user.

  • Source health and enabled/disabled controls
  • Rule plus LLM relevance filtering
  • Strategic-gap qualification before opportunities

Evidence-backed trust

Every candidate should trace back to the evidence graph.

  • Raw post URL and text
  • Extracted finding metadata
  • Company/source breadth and run telemetry

Agent learning loop

The product becomes agent-like when user preferences shape future runs.

  • Saved/dismissed gaps influence ranking
  • Muted sources and ignored themes steer filtering
  • Follow-ups become intent for deeper research
